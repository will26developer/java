# Patrones de diseño en Java

Carpeta con ficheros independientes. Cada fichero explica un patrón concreto con:

- Objetivo
- Cuándo usarlo
- Ventajas
- Desventajas
- Ejemplo ejecutable en Java

## Cómo ejecutar

Compila uno de los ficheros:

```bash
javac 11_Strategy.java
java StrategyEjemplo
```

Algunos ficheros tienen clases auxiliares no públicas dentro del mismo archivo para facilitar el estudio.
