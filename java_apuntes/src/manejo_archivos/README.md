# Manejo de Archivos en Java

Este paquete contiene varios ficheros Java separados por tema:

1. File básico
2. Escribir archivos con FileWriter
3. Leer archivos con BufferedReader
4. Files y Path con NIO
5. Copiar, mover y borrar archivos
6. Listar carpetas
7. Serialización de objetos
8. Leer CSV
9. Archivos properties
10. Buenas prácticas

## Cómo ejecutar

Compila un archivo:

```bash
javac 01_File_Basico.java
java FileBasico
```

Algunos archivos generan archivos auxiliares como `.txt`, `.csv`, `.dat` o `.properties`.
